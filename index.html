How a verdict is made

  1. Read the claim

    We pull out the key terms and drop filler words, so a long forward becomes a clean search.

  2. Search real sources

    Google Fact Check Tools for published fact-checks, Wikipedia for reference articles, and GDELT for how news outlets covered it.

  3. Show the evidence

    We only say true or false when professional fact-checkers did. Everything else is labelled for what it is.
